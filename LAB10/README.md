# LAB10 — Mã hóa đối xứng cổ điển

- Họ và tên: Phạm Gia Bảo
- MSSV: 1150080043
- Lớp: 11_DH_CNPM1

Dự án Java Swing sử dụng Maven để thực hành sáu thuật toán mã hóa cổ điển.
Chạy từ thư mục LAB1_TuLam bằng lệnh `mvn clean compile exec:java`.

Đã chạy sáu form riêng, form tổng hợp và phần phân tích mật mã trên Ubuntu.
Phần lưu lịch sử vào SQL Server chưa kiểm thử và chưa có ảnh SSMS.
